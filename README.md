# Hari Hara Developers website

20-page static HTML/CSS/JS website for Hari Hara Developers, built by Techsak Technologies.

## Deployment
Upload the contents of this repository to the domain document root (typically `public_html`). Directory-style routes require Apache or equivalent support for `index.html`.

## Before launch
- Replace CSS text-based logo with approved official image assets where available.
- Replace illustrative Unsplash photographs with client-approved licensed imagery and actual project photographs.
- Confirm company contact details and WhatsApp number.
- Configure a secure lead collection endpoint. The contact form deliberately does **not** submit to Google Sheets or claim success until configured.
- Review all legal content, create approved privacy policy, and verify actual company facts.
- Replace placeholder domain in `sitemap.xml` and `robots.txt`.
- Configure SEO canonical URLs, analytics, social previews, and schema after receiving verified metadata.
